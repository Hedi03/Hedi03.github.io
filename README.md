# CV étudiant — ISET Radès

## Fichiers
- `index.html` : contenu du CV.
- `style.css` : mise en forme du site.

## Avant publication
1. Ouvre `index.html` dans Visual Studio Code.
2. Remplace les années de formation et l'année du stage.
3. Remplace l'adresse email et les liens GitHub/LinkedIn.
4. Remplace les exemples de projets par tes projets réellement réalisés, ou supprime-les.
5. Tu peux remplacer le cercle « HB » par une photo si tu le souhaites.

## Publication avec GitHub Pages
1. Crée un dépôt public GitHub nommé `TON-PSEUDO.github.io`.
2. Ajoute `index.html` et `style.css` à la racine du dépôt.
3. Ouvre **Settings > Pages**.
4. Dans la source de déploiement, choisis **Deploy from a branch**, puis la branche `main` et le dossier `/(root)`.
5. Enregistre et attends la publication. L'adresse sera `https://TON-PSEUDO.github.io`.

Pour modifier le site après publication, modifie les fichiers puis envoie les changements sur GitHub.
